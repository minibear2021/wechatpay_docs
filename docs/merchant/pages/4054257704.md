## 一、转账回调通知的密钥配置与 IP 放通

| 注意事项 | 说明、正确应该怎么做 | 不做会怎么样 |
| --- | --- | --- |
| 转账回调须配置APIv3密钥并放通官方IP段 | 说明：商家转账回调须使用已配置的 APIv3 密钥解密通知数据，并允许微信支付回调来源访问 `notify_url`；防火墙或安全组只放通固定单个 IP 不足以保证各回调出口可达。<br>正确应该怎么做：① 在商户平台完成 APIv3 密钥设置，并用同一密钥解密回调资源；② 按《回调通知注意事项》列出的当前微信支付回调 IP 段配置防火墙、安全组或 WAF；③ 将回调地址配置为公网可访问的 HTTPS 全路径；④ 接收通知后验签、幂等处理，并保存 `Request-ID` 和报文；⑤ 未收到回调时主动查单兜底。<br>典型反例：只放通测试环境的一个临时出口 IP，正式环境切流后由另一地域节点回调而无法访问。<br>见 [4012072195-配置APIv3密钥](https://pay.weixin.qq.com/doc/v3/merchant/4012072195.md)、 [4012712115-商家转账回调通知](https://pay.weixin.qq.com/doc/v3/merchant/4012712115.md)、 [4012716434-发起转账](https://pay.weixin.qq.com/doc/v3/merchant/4012716434.md)、 [4012075420-回调通知注意事项](https://pay.weixin.qq.com/doc/v3/merchant/4012075420.md)、 [4012715211-商家转账开发指引](https://pay.weixin.qq.com/doc/v3/merchant/4012715211.md) | 防火墙或 WAF 会拦截微信支付回调，商户收不到转账结果通知，只能依赖主动查单发现状态变化；转账单即使已 `SUCCESS` 且款项到账，商户仍收不到成功回调，只能依赖主动查单发现终态。 |

## 二、旧版商家转账到零钱的额度与迁移

| 注意事项 | 说明、正确应该怎么做 | 不做会怎么样 |
| --- | --- | --- |
| 旧版商家转账单笔额度为200元且不可提额 | 说明：旧版“商家转账到零钱”使用 `/v3/transfer/batches` 接口，其单笔上限仍为 200 元且不支持提额；新版“商家转账”已上线并支持在限额范围内按申请结果调整额度。<br>正确应该怎么做：① 根据实际调用 URL 判断当前使用的是旧版 `/v3/transfer/batches` 还是新版 `/v3/fund-app/mch-transfer/transfer-bills`；② 旧版商户登录商户平台查看站内信，按升级入口申请新版权限；③ 权限开通后按产品场景完成资料审核，再接入新版接口；④ 在新版商户平台中按实际业务申请并设置单笔、单用户及单日额度，以审核结果为准。<br>典型反例：继续使用旧版批次转账接口，却在后台按新版额度页面调高额度后直接发起超过 200 元的转账。<br>见 [4015273741-商家转账到零钱升级说明](https://pay.weixin.qq.com/doc/v3/merchant/4015273741.md)、 [4013747667-设置转账额度](https://pay.weixin.qq.com/doc/v3/merchant/4013747667.md)、 [4013774966-订单失败原因说明](https://pay.weixin.qq.com/doc/v3/merchant/4013774966.md) | 明细状态返回 `FAIL`，失败原因为 `TRANSFER_QUOTA_EXCEED`，提示超过用户单笔收款额度，转账无法完成。 |

## 三、商户 API 证书与平台证书

| 注意事项 | 说明、正确应该怎么做 | 不做会怎么样 |
| --- | --- | --- |
| 平台证书须在到期前完成更换与多证书验签 | 说明：商户 API 证书与平台证书用途不同；平台证书用于 V3 应答和回调验签及敏感字段加密，商户应在平台证书和微信支付公钥之间选择一种验签方式。<br>正确应该怎么做：① 通过证书密钥概览确认当前使用的是平台证书还是微信支付公钥；② 继续使用平台证书时，在到期前实现多证书验签并通过 `Wechatpay-Serial` 选择对应证书；③ 登录商户平台账户中心 \> API 安全 > 平台证书，获取并部署新证书后完成灰度；④ 也可按官方指引切换到无过期时间的微信支付公钥。<br>典型反例：只更新了商户 API 证书，便认为 V3 应答和回调使用的平台证书也已同步更新。<br>见 [4024350132-证书密钥概览](https://pay.weixin.qq.com/doc/v3/merchant/4024350132.md)、 [4012068814-平台证书产品介绍](https://pay.weixin.qq.com/doc/v3/merchant/4012068814.md)、 [4012068829-平台证书更换操作指引](https://pay.weixin.qq.com/doc/v3/merchant/4012068829.md) | 平台证书到期而系统未完成新证书部署或多证书验签时，V3 应答和回调验签会失败，影响接口调用及转账结果处理。 |
| 转账须使用已开通权限商户号及其对应证书 | 说明：发起商家转账的商户号必须具备商家转账权限，商户号、API证书序列号和签名私钥必须属于同一套商户API证书。<br>正确应该怎么做：① 在商户平台确认具体哪个 `mchid` 已开通商家转账；② 下载该 `mchid` 对应的 `apiclient_cert.pem`、 `apiclient_key.pem` 并记录对应序列号；③ 使用该商户号和这套证书签名调用转账接口；④ 核对应答中的 `mch_id` 与配置一致。<br>典型反例：后台确认的是子商户已开通，接口仍用服务商商户号及服务商证书签名。<br>见 [4012716434-发起转账](https://pay.weixin.qq.com/doc/v3/merchant/4012716434.md)、 [4012365347-签名错误排查](https://pay.weixin.qq.com/doc/v3/merchant/4012365347.md)、 [4020801391-错误码](https://pay.weixin.qq.com/doc/v3/merchant/4020801391.md) | 使用无权限商户号时返回 `1001` 权限未开通；使用不匹配证书时提示「无有效的商户证书」或返回商户证书序列号、签名相关错误，转账无法发起。 |

## 四、接口安全 IP 白名单配置

| 注意事项 | 说明、正确应该怎么做 | 不做会怎么样 |
| --- | --- | --- |
| 商家转账出资接口须配置实际出口IP白名单 | 说明：商家转账出资类接口必须使用已配置的请求来源 IP 调用；授权、查询授权关系、查单等不出资接口不校验该白名单。<br>正确应该怎么做：① 登录商户平台，进入产品中心 > 运营工具 > 商家转账 > 前往功能 \> 安全能力；② 在接口 IP 中新增实际发起请求的公网出口 IP，并同步核对 NAT 网关、负载均衡等出口地址；③ 配置生效后再发起转账，遇到 IP 拦截错误时按错误码核对白名单。<br>典型反例：仅登记应用服务器内网 IP，遗漏统一 NAT 或负载均衡的实际公网出口 IP。<br>见 [4013751010-设置接口安全IP](https://pay.weixin.qq.com/doc/v3/merchant/4013751010.md)、 [4012715211-商家转账开发指引](https://pay.weixin.qq.com/doc/v3/merchant/4012715211.md)、 [4020801391-商家转账错误码](https://pay.weixin.qq.com/doc/v3/merchant/4020801391.md)、 [4013778940-商家转账常见问题](https://pay.weixin.qq.com/doc/v3/merchant/4013778940.md)、 [4015273741-商家转账到零钱升级说明](https://pay.weixin.qq.com/doc/v3/merchant/4015273741.md) | 返回 `268491067` 或提示「此IP地址不允许调用接口，请按开发指引设置」，出资接口无法调用；返回 `INVALID_REQUEST` 或错误码 `268491067`，提示「此IP地址不允许调用接口，请按开发指引设置」，转账接口无法调用。 |

## 五、转账场景申请、报备信息与收款感知

| 注意事项 | 说明、正确应该怎么做 | 不做会怎么样 |
| --- | --- | --- |
| 发起转账前须申请并获取对应转账场景 | 说明：发起转账使用的 `transfer_scene_id` 必须是当前商户已在商户平台申请并获取的转账场景 ID，不能只凭接口示例直接写入场景编号。<br>正确应该怎么做：① 登录商户平台，进入产品中心 > 商家转账 \> 产品设置；② 按实际业务申请对应场景并记录返回的场景 ID；③ 将场景 ID 配置到服务端，避免前端自行传值；④ 调用前核对场景、金额范围与场景报备要求。<br>典型反例：未在商户平台申请场景，代码中直接硬编码 `1000` 或其他示例场景 ID。<br>见 [4012711988-商家转账产品介绍](https://pay.weixin.qq.com/doc/v3/merchant/4012711988.md)、 [4013778940-商家转账常见问题](https://pay.weixin.qq.com/doc/v3/merchant/4013778940.md) | 返回 `INVALID_REQUEST`「你尚未获取该转账场景」，或订单失败原因返回 `TRANSFER_SCENE_INVALID`，转账无法受理。 |
